# Click Paste Privacy Policy

Public English and Simplified-Chinese privacy policy for the Click Paste iOS app and Keyboard Extension.

- English: https://abreadtree.github.io/click-paste-privacy/
- 简体中文: https://abreadtree.github.io/click-paste-privacy/zh-cn/
- English support: https://abreadtree.github.io/click-paste-privacy/support/
- 简体中文支持: https://abreadtree.github.io/click-paste-privacy/zh-cn/support/
- Contact: GitHub Issues in this repository

The site is hand-written static HTML/CSS. It contains no analytics, ads, cookie-setting code, forms, remote fonts, client-side JavaScript, package manager, or static-site generator.

## Verify

```sh
python3 -m unittest discover -s tests -v
```

GitHub Pages deploys the staged policy and support HTML, shared CSS, icon, Chinese routes, .nojekyll file, and 404 page.
