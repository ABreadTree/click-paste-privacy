隐私政策

剪贴板内容只保留在你的设备上。不分析、不上传、不投放广告。

最后更新：2026 年 7 月 21 日

隐私概览

隐私源于本地设计。Click Paste 是一款用于重复使用已复制文本和图片的 iOS 应用及自定义键盘扩展。它不需要账户，也不是后台剪贴板监控器或云剪贴板服务。

同意与剪贴板访问

在你通过 Click Paste 应用明确同意前，剪贴板历史保持关闭。自动缓存需要同时满足：已同意、已开启自动缓存、已开启完整访问，并且键盘可见且处于活跃状态。

键盘隐藏、非活跃或处于后台时，不会读取或轮询剪贴板。类似网址的字符串按普通文本处理。

本地存储与保留期限

剪贴板内容只保存在设备上的 App Group 容器中。SQLite 保存元数据，本地文件保存图片、缩略图和较大的内容正文。

  • 默认最多保留最近 50 个活动项目。
  • 未固定项目会在 7 天后过期；按默认规则，已固定项目不会过期。
  • 图片共用 200 MB 的本地存储预算。

为什么请求完整访问

完整访问允许键盘在可见且活跃时读取系统剪贴板，并与主应用共享本地缓存。未开启完整访问时，键盘仍可显示设置和状态，但剪贴板历史不可用。

由你掌控

你可以随时撤销同意。“关闭预览”不会删除内容；删除所选项目会移除该缓存项目。

“归档本地缓存”通过标记归档来隐藏活动项目。“清除本地缓存”在确认后会从设备永久删除活动及已归档的元数据和内容文件。

收集、共享与追踪

Click Paste 不会上传剪贴板文本、类似网址的字符串、图片、预览、输入的按键、输入上下文或设置。应用不包含广告或第三方分析 SDK，并声明不追踪、也不收集数据。

唯一声明的必需原因 API 是 App Group UserDefaults，原因代码为 1C8F.1。

图片处理

图片插入属于尽力而为。部分宿主应用不接受来自自定义键盘的图片；Click Paste 提供复制备用方式，不承诺在所有应用中都能插入图片。

关于此网站

本页面不添加分析、广告、Cookie 设置代码、表单、远程字体或客户端脚本。网站由 GitHub Pages 托管；GitHub 可能依据 GitHub 隐私声明，出于安全和服务运行目的记录 IP 地址及请求元数据。

政策变更

如果 Click Paste 的数据处理行为发生重大变化，我们会在发布前更新本页面及适用的 App Store 隐私披露。页面顶部日期表示当前版本。

联系我们

如有隐私问题，请在公开的隐私政策仓库中创建 Issue。提交 Issue 需要 GitHub 账户，并受 GitHub 政策约束。请勿提交剪贴板内容、输入文本、图片或其他敏感信息。
