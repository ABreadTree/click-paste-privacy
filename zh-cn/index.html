Click Paste

隐私政策

Click Paste 只在本机处理剪贴板内容，不上传数据，也不使用广告或分析服务。

最后更新：2026 年 7 月 21 日

概览

所有处理均在本机完成。Click Paste 由一个 iOS 应用和一个自定义键盘组成，用于保存和重复使用剪贴板中的文字与图片。它不要求注册账户，也不会在后台监控剪贴板或把内容同步到云端。

何时读取剪贴板

首次使用时，只有在你于 Click Paste 应用中明确同意后，剪贴板历史才会开启。自动保存还要求你开启“自动缓存”和“完整访问”，并且 Click Paste 键盘当前可见、正在使用。

键盘被收起、暂停使用或应用进入后台后，Click Paste 不会继续读取或轮询剪贴板。网址也会作为普通文本保存和输入。

内容如何保存在本机

内容存放在 iOS 为 Click Paste 应用和键盘分配的 App Group 本地容器中。SQLite 用于保存项目资料；图片、缩略图和较长的文本则保存为本地文件。

  • 默认最多保留最近 50 个未归档项目。
  • 未固定的项目默认在 7 天后过期；固定项目不会按此规则过期。
  • 所有图片合计最多使用 200 MB 本地空间。

为什么需要“完整访问”

开启“完整访问”后，键盘才能在显示并正在使用时读取系统剪贴板，并与 Click Paste 应用共用本地缓存。若未开启，键盘仍会显示设置提示和当前状态，但不会提供剪贴板历史。

你的选择

你可以随时撤回同意。“关闭预览”只会退出当前预览，不会删除内容；“删除所选项目”会从本地缓存中移除该项目。

“归档本地缓存”会隐藏当前列表中的项目，但数据仍保存在本机。“清除本地缓存”需要再次确认，确认后会永久删除未归档和已归档的记录及相关文件。

数据收集与追踪

Click Paste 不会将剪贴板文字、网址、图片、预览内容、按键、输入上下文或设置发送给开发者或第三方。应用不含广告和第三方分析 SDK，也不进行跨应用追踪。

应用使用 App Group UserDefaults 保存共享设置，并按 Apple 要求声明必需原因代码 1C8F.1。

本网站

这个网站不使用分析工具、广告、Cookie、表单、远程字体或客户端脚本。网站托管在 GitHub Pages。为了保障安全和维持服务，GitHub 可能会按照其 隐私声明 记录 IP 地址和请求信息。

政策更新

如果 Click Paste 对数据的处理方式有重要变化，我们会在新版本发布前更新本页及相应的 App Store 隐私说明。页面顶部的日期是本政策最近一次更新时间。

联系我们

如需咨询隐私问题，可在本政策的 GitHub 仓库中创建 Issue。创建 Issue 需要登录 GitHub，并受 GitHub 的相关政策约束。请勿在 Issue 中提交剪贴板内容、输入文字、图片或其他敏感信息。
